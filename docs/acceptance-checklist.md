# 健康负面效果验收清单

## 基础视觉

- [ ] `F8` 打开实验室，`Mock` 来源不会修改服务器或存档。
- [ ] 轻度流血只在外围出现暗红渗色，准星中心和屏幕中央保持清晰。
- [ ] 重度流血比轻度更厚、更暗，脉冲不超过每秒一次且无连续闪白。
- [ ] 单腿骨折显示稀疏白灰裂纹；移动时镜头压沉幅度很小，静止时不持续抖动。
- [ ] 高疼痛显示冷色外围波纹和稳定疼痛卡，不使用强模糊、`nausea` 或白屏。
- [ ] 组合预设同时显示不同形状的状态卡，颜色不是唯一编码。

## 音频

- [ ] 进入或升级状态只播放一次 onset 声，不因同步包重复触发。
- [ ] 流血脉搏、疼痛呼吸、骨折脚步有明显冷却，不形成机关枪式循环。
- [ ] 音效字幕能在字幕设置中显示，音量受独立 `effectVolume` 控制。
- [ ] 止痛/清除伤情后有短暂缓解声，视觉和音频平滑退出。

## 无障碍与兼容

- [ ] `Screen effects: OFF` 仍保留稳定图形 + 文字状态卡，并关闭镜头动态。
- [ ] `Screen effects: LOW` 明显减弱叠层但不改变状态逻辑。
- [ ] `Reduce motion` 后镜头 pitch/roll 为零。
- [ ] 关闭疼痛色散、流血脉搏和打开高对比度后，设置在重连/重启后仍可复现。
- [ ] F1、打开其他界面、重连和退出世界不会留下旧叠层或音效状态。
- [ ] 不带 TarkovMod 的普通 `runClient` 能启动并使用 Mock；带 `-PwithTarkov=true` 时只有完整权威快照到达后才读取 live 状态。
